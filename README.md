# SAWI — Website

موقع ستاتيك جاهز للرفع، مش محتاج سيرفر ولا قاعدة بيانات.

## الملفات

```
index.html            الصفحة الرئيسية
project.html          صفحة المشروع (بتعرض أي مشروع من الرابط: project.html?p=trust)
favicon.svg           أيقونة التاب
assets/css/style.css  التصميم
assets/js/content.js  ← كل الكلام والمشاريع والإيميل واللينكات هنا
assets/js/main.js     الحركة والتفاعل
assets/media/         الفيديوهات والصور
```

## الرفع على Netlify (أسهل طريقة، مجاناً)

1. ادخل على https://app.netlify.com/drop
2. اسحب فولدر `sawi-site` كله وارميه في الصفحة.
3. بعد دقيقة هيديك لينك شغال زي `sawi-xxxx.netlify.app`.
4. عشان الدومين بتاعك: Site settings ← Domain management ← Add a domain.

بديل: Vercel أو GitHub Pages، نفس الفكرة، ارفع الفولدر كما هو.

## تعديل المحتوى

افتح `assets/js/content.js` بأي محرر نصوص:

- **الإيميل واللينكات:** أول السطور فوق (`email`, `behance`, `linkedin`, `company`).
- **مشروع جديد:** انسخ أي بلوك `{ ... }` جوه `projects`، غيّر الاسم والـ `slug`، وحط الفيديوهات في `assets/media/`.
- **ترتيب المشاريع:** نفس ترتيبها في الملف.
- **مقاس الكارت:** `layout` = `"wide"` عريض · `"large"` كبير · `"tall"` طولي · `"half"` نص.

كل سطر مكتوب جنبه `TODO` محتاج تراجعه.

## الفيديوهات

- `*-loop.mp4` ← نسخة خفيفة من غير صوت، بتشتغل لوحدها في الكروت.
- `*-film.mp4` ← النسخة الكاملة بالصوت في صفحة المشروع.

لو عايز جودة أعلى، استبدل ملفات `*-film.mp4` بنفس الاسم (يفضل أقل من 20 ميجا للفيلم).
